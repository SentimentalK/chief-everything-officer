# CEO Workspace Router

Use the smallest relevant area.

## Tasks

Purpose:
Current or future work, goals, decisions still being acted on, and next actions.

Typical path:
tasks/

Use when:
The user asks what they are working on, what remains to be done, or wants to update active work.

## Context

Purpose:
Stable user preferences and reusable personal context.

Typical path:
context/

Use when:
The answer depends on how the user generally prefers, behaves, or decides.

## Records

Purpose:
Specific personal facts and reference information.

Typical path:
records/

Use when:
The user asks for a precise fact about themselves.

## Journal

Purpose:
Meaningful past events and chronology.

Typical path:
JOURNAL.md or journal/

Use when:
The user asks what happened or when something happened.

## Unknown Cases

If no category clearly applies:

1. Search the workspace.
2. Read only relevant results.
3. Do not invent a new permanent category merely to answer one request.

## Stop

If the relevant user data already answers the task, stop retrieving.
Do not read unrelated areas just in case.
