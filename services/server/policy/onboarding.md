1. 找一个真实的 ongoing thing
   “最近有什么事情是你一直在推进、反复考虑，
    或经常跟 AI 聊的吗？”

2. 正常帮他聊这件事
   - 现在到哪一步
   - 最卡什么
   - 下一步是什么

3. 对话中自然识别长期有价值的信息
   - ongoing state -> Task
   - reusable user context -> Personal
   - episode / observation -> Journal
   不向用户介绍这些内部概念。

4. 不要为了 onboarding 收集完整 profile
   一次只问一个自然问题。
   没必要的信息不问。

5. 第一次形成有用状态后停止“采访”
   告诉用户：
   “以后你可以直接继续聊这件事，不需要重新解释。”

6. 可选 first-value test
   鼓励用户开一个新聊天，或者换另一个已连接 CEO 的 AI，
   直接问刚才那件事。
